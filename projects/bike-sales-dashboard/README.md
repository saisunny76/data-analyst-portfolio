# Bike Sales Dashboard (Excel)

An interactive Excel dashboard that explores which customers buy bikes, using PivotTables, charts, and slicers.

## Business Question
Which customer groups (gender, age bracket, commute distance, and region) are most likely to buy a bike, and how does income differ between buyers and non-buyers?

## Dataset
- `bike_buyers`: 1,000 customers, 14 columns
- Fields include marital status, gender, income, children, education, occupation, home ownership, cars, commute distance, region, age, age bracket, and bike purchase status

## Tools
- Microsoft Excel

- PivotCharts
- Slicers
- Basic formulas and data cleaning

## What I Did
1. Cleaned the raw dataset by removing duplicates, standardizing text values, checking for missing values, and creating an Age Bracket column.
2. Built PivotTables to analyze:
   - Average income by gender and purchase status
   - Bike purchases by commute distance
   - Bike purchases by age bracket
   - Bike purchases by region
3. Created charts from each PivotTable and combined them into a single dashboard layout.
4. Added slicers so the dashboard can be filtered interactively by key customer segments.

## Key Findings
- 481 of 1,000 customers (48.1%) bought a bike.
- Middle-aged customers (31–54) had the highest purchase rate, making up the majority of bike buyers.
- Customers with shorter commutes were more likely to purchase bikes.
- Buyers had a higher average income than non-buyers.
- Purchase rates varied by region, with the Pacific region showing the strongest demand.

## Recommendations
- Focus marketing efforts on middle-aged customers with shorter commute distances.
- Test targeted promotions for regions with lower purchase rates, such as North America.
- Use income-based segmentation to build personalized offers for likely buyers.
